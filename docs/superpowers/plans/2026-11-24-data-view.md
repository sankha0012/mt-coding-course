# The Data tab Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Data tab in the right pane shows the tables of the waiting step (columns, row count, first 10 rows) so the learner need not scroll up.

**Architecture:** A small `player/tables.py` reads the CSV files of a folder. `Player.data()` picks the folder from the current step, caches the result per folder, and `GET /api/data` serves it. The page gains Try / Data tabs in the existing pane and two edge buttons that open the pane on either view.

**Tech Stack:** Python 3.12, FastAPI, stdlib `csv`, plain HTML/JS/CSS, pytest.

**Spec:** `docs/superpowers/specs/2026-11-24-data-view-design.md`

## Global Constraints

- Rule 6: the tab shows data only: no lesson text, syntax, prompts or earlier answers.
- The route is read only. It never changes engine state, the ladder, the returns queue, `events` or `questions`.
- The client never sends a folder name. The server picks it from the current step.
- Rows: the first 10 of each table, no paging. Empty cells go out as `null` and show as a faint "empty".
- Never delete, overwrite or reset `progress/progress.db`. Tests use a temporary folder.
- No new dependency. No timer, count or score for the learner.
- No em dashes in docs.

```python
import csv
from pathlib import Path


def sample(folder, ext=False, limit=10):
    """The tables of a folder: name, columns, the first rows and the true row count. Empty cells are None."""
    out = []
    for f in sorted(Path(folder).glob("*.csv")):
        with open(f, newline="", encoding="utf-8") as h:
            reader = csv.reader(h)
            columns = next(reader, [])
            rows, total = [], 0
            for r in reader:
                if not r:
                    continue
                total += 1
                if total <= limit:
                    rows.append([v if v != "" else None for v in r])
        out.append({"name": f.name if ext else f.stem, "columns": columns, "rows": rows, "total": total})
    return out
```

```python
    def data(self):
        """The tables of the step now waiting, for the Data tab. Read only, not logged."""
        with self.lock:
            _, name, st = self._current()
            step = self.engines[name].steps[st["playing"]["step"]]
            key = (step.get("data", ""), Engine._lang(step) == "python")
        if key not in self._tables:  # the lock is free while a big folder is read
            self._tables[key] = tables.sample(self.runner.path(key[0]), ext=key[1])
        return {"data": key[0], "tables": self._tables[key]}
```

```js
  let view = keep.get('play-view') === 'data' ? 'data' : 'try';
  let dataKey = null, shownKey = null;

  const dataTable = t => {
    const box = el('div');
    const note = t.total > t.rows.length
      ? t.total.toLocaleString() + ' rows, first ' + t.rows.length + ' shown' : t.total.toLocaleString() + ' rows';
    const table = el('table');
    const hr = el('tr');
    t.columns.forEach(c => hr.appendChild(el('th', null, c)));
    table.appendChild(hr);
    t.rows.forEach(r => {
      const tr = el('tr');
      r.forEach(v => {
        const td = el('td');
        if (v === null) td.appendChild(el('span', 'empty', 'empty')); else td.textContent = v;
        tr.appendChild(td);
      });
      table.appendChild(tr);
    });
    const wrap = el('div', 'tablewrap'); wrap.appendChild(table);
    box.append(el('div', 'total', note), wrap);
    return box;
  };

  const drawData = tables => {
    const chips = el('div', 'tabs');
    const grid = el('div');
    const buttons = tables.map((t, i) => {
      const b = button(t.name, () => show(i), 'tab');
      chips.appendChild(b);
      return b;
    });
    const show = i => {
      buttons.forEach((b, j) => b.classList.toggle('on', i === j));
      grid.replaceChildren(dataTable(tables[i]));
    };
    dataView.replaceChildren(chips, grid);
    if (tables.length) show(0);
    else dataView.replaceChildren(el('p', 'hint', 'There is no data for this step.'));
  };

  const loadData = async () => {
    if (!panel.isConnected || view !== 'data') return;
    try {
      const d = await api('/api/data');
      if (d.data === shownKey && dataKey !== null) return;  // same dataset: stay as it is
      shownKey = d.data; dataKey = d.data;
      drawData(d.tables);
    } catch (e) {
      dataKey = null;
      dataView.replaceChildren(el('p', 'hint', 'The data did not load.'));
    }
  };

  const showView = v => {
    view = v; keep.set('play-view', v);
    tryView.hidden = v !== 'try'; dataView.hidden = v !== 'data';
    Object.entries(viewButtons).forEach(([n, b]) => b.classList.toggle('on', n === v));
    if (v === 'try') { ed.sync(); ed.box.focus(); } else loadData();
  };
  onView = loadData;
```
